# PyCompassNode Attributes

### `pos_x (type 'int')`

The x position of a node in the Batch schematic.

Value range:

- Min: -2147483647
- Max: 2147483647

### `pos_y (type 'int')`

The y position of a node in the Batch schematic.

Value range:

- Min: -2147483647
- Max: 2147483647

### `name (type 'str')`

The name of the node in the Batch schematic.

### `collapsed (type 'bool')`

The collapsed status of a node in the Batch schematic.

Value range:

- True
- False

### `note (type 'str')`

The Node's note.

### `note_collapsed (type 'bool')`

The collapsed status of a note in the Batch schematic.

Value range:

- True
- False

### `selected (type 'bool')`

Select a Node in the Batch schematic.

Value range:

- True
- False

### `type (type 'str')`

Return the type of the node.

### `width (type 'int')`

The width attribute of the Compass node.

Value range:

- Min: 200
- Max: 2147483647

### `height (type 'int')`

The height attribute of the Compass node.

Value range:

- Min: 200
- Max: 2147483647

### `colour (type 'tuple')`

The Colour attribute of the Compass node.

Value range:

- (0.0, 0.0, 0.0)
- (1.0, 1.0, 1.0)
