# PyMediaHub Attributes

Object allowing manipulation to the **MediaHub** module.

| Command | Type | Description |
|---|---|---|
| `flame.mediahub.files` | PyMediaHubTabFiles | **Files** tab of the **MediaHub** module. |
| `flame.mediahub.archives` | PyMediaHubTab | **Archives** tab of the **MediaHub** module. |
